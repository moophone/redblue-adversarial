## 机制正本

模型实际加载的是技能：`D:\1a个人\dsh-home\skills\redblue-adversarial\SKILL.md`。
该技能是**操作入口**，完整规范指向本目录的 02/03。

## 版本约定（避免再出现并存）

- 协议只保留**一个版本**，废弃版本进 `_archive/`（单个 zip 或子目录），不进根目录。
- 需要改协议时：直接改 02/03，旧版先归档再改。
- 本机没有 git，所以归档就是版本库。
